## 💰 经济模型

### 代币总量与分配

**FF Token 总量：21,000,000 枚**

```
📊 代币分配方案：
├─ 流动性池：20,000,000 FF (95.23%)
└  └──100日自动销毁：3,000,000 FF (14.28%)
├─ 邀请推广：2,000 FF (0.00009523%)
└─ 团队销毁：988,000 FF (4.7%)
```

### 收益来源

#### 1️⃣ 静态挖矿收益（每日 0.8%）

- 充值 BNB 自动转换为 LP 并开始挖矿
- 每日 12:00 生成快照，计算当日收益
- 收益以 FF Token 形式发放
- 可随时提取，无锁定期

**收益计算公式：**
```
用户每日收益 = (用户 LP 份额 / 总 LP 份额) × 每日静态奖励池 × 0.8%
```


#### 4️⃣ 税收分红（私募专享）

私募用户享受交易税收分红权益：

- **分红来源**：FF Token 交易手续费（买入 2% + 卖出 2%）
- **分红对象**：1500 名私募用户 + 达到 V1 及以上的节点用户
- **分红方式**：按份额平均分配，随时可提取
- **永久权益**：一次获得，终身享受

**税收分配：**
``` 
分红池 → 私募用户 + V1+ 节点用户平均分配
```

## 🎮 参与流程

### 第一步：注册账户

**注册方式：向推荐人地址转账 0.001 FF Token**

```
操作步骤：
1. 获取推荐人钱包地址
2. 向推荐人转账 0.001 FF Token
3. 系统自动完成注册绑定
4. 开始享受推荐关系和奖励
```

⚠️ **重要提示：**
- 注册交易会触发合约逻辑，Gas 费略高于普通转账
- 如交易失败，请在钱包中手动提高 Gas Limit
- 必须先注册后充值，否则无法获得奖励

### 第二步：充值挖矿

**充值方式：向挖矿合约转账 BNB**

```
合约地址：
充值金额：0.2 - 10 BNB（必须是 0.2 的整数倍）
单地址限额：累计最多 10 BNB
```

**充值后自动执行：**
1. ✅ BNB 自动转换为 LP 并添加到流动性池
2. ✅ 获得 FFLP-11 凭证（可随时赎回）
3. ✅ 开始产生每日 0.8% 的静态收益
4. ✅ 推荐人获得 10% 直推奖励（BNB）
5. ✅ 上级节点获得相应节点奖励（BNB）
6. ✅ 如有历史未提取收益，自动结算

### 第三步：提取收益

**提取方式：向挖矿合约转账 0 BNB**

```
合约地址：
转账金额：0 BNB
操作结果：提取所有累积的挖矿收益（FF Token）
```

**提取特点：**
- 💎 无手续费，无锁定期
- 💎 一次性提取所有累积收益
- 💎 上级节点获得提现奖励（FF Token）
- 💎 最多可提取 30 天累积收益

### 第四步：赎回 LP（可选）

如需退出或调整仓位，可随时赎回充值 LP：

```
操作方式：
1. 调用合约
2. 选择赎回数量
3. 确认交易
4. 获得对应的 BNB
```

⚠️ **注意事项：**
- 充值 LP（FFLP）可随时赎回
- 空投 LP（FFLP-L）锁仓 6 年后可赎回
- 赎回会减少后续挖矿收益
